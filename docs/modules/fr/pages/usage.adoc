= Utilisation

== AsciiDoc vers PDF (Bibliotheque)

[source,crystal]
----
require "asciidoc_pdf"

# Convertir AsciiDoc en PDF
source = File.read("document.adoc")
converter = AsciidocPDF::Converter.convert(source)
converter.save("document.pdf")

# Avec un theme personnalise
theme = AsciidocPDF::Theme.new
theme.base_font_size = 12.0
theme.heading_h1_font_size = 28.0

converter = AsciidocPDF::Converter.convert(source, theme)
converter.save("document.pdf")
----

== Generation PDF bas niveau

[source,crystal]
----
require "pdf"

doc = PDF::Document.new

doc.page(width: 595.28, height: 841.89) do |page|
  page.font("Helvetica", size: 24)
  page.fill_color(0.0, 0.0, 0.0)
  page.text("Bonjour !", at: {72, 750})
end

File.open("sortie.pdf", "w") { |f| doc.write(f) }
----

== Lecture d'un PDF existant

Depuis 0.3.0, `PDF::Reader` ouvre un PDF existant, analyse son graphe
d'objets et expose les pages et les objets indirects.

[source,crystal]
----
require "pdf"

reader = PDF::Reader.open("document.pdf")

puts "Version PDF : #{reader.version}"
puts "Nombre de pages : #{reader.pages.size}"

reader.pages.each_with_index do |page, i|
  puts "Page #{i + 1} : #{page.width} x #{page.height}"
end
----
