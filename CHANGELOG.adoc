== v0.3.1 — 2026-04-23

=== Fixed

* **SVG `path_parser` tokenizer**: fix an infinite loop triggered by
  certain compact path-data strings. When a number ended with a `.`
  that was immediately followed by another `.` starting the next
  number (e.g. `4.4.8` or `3 0.5.7`, a pattern common in tightly
  packed flag SVGs), the inner number-parsing loop would break on
  the very same `.` it had just stopped at without advancing `i`,
  and the outer loop would spin forever at 100 % CPU. The fix
  unconditionally consumes the first character of a numeric token.
* Added `PDF::SVG::PathParser` specs covering the degenerate case
  and a reduced extract of the Brazil flag path that used to hang.

== v0.3.0 — 2026-04-20

=== Added

* Read existing PDF files via the new `PDF::Reader` module
  (syntactic parser, page and indirect-object access, groundwork
  for incremental-update save).
* Associated specs (`spec/pdf/parser_spec.cr`,
  `spec/pdf/reader_spec.cr`) and fixtures generated by
  `spec/fixtures/generate_fixtures.cr`.

=== Changed

* Ran `crystal tool format` across the whole existing code base.

== v0.2.0 — 2026-04-13

=== Added

* Ported six Prawn features: kerning, gradients, encryption, XMP
  metadata, stamps and icon fonts.

=== Fixed

* Correct UTF-8 encoding for Type1 fonts (WinAnsiEncoding).
* Shared TrueType font references.

=== Other

* Completed ameba exclusions in CI.

== v0.1.0 — 2026-04-10

=== Added

* First public release: low-level PDF engine ported from
  https://github.com/watzon/pdf.cr[watzon/pdf.cr], itself inspired
  by the Ruby gem Prawn.
* Coverage: multiple pages, Type1 and TrueType fonts (Unicode),
  vector graphics, JPEG/PNG images, formatted text, bounding boxes
  and columns, tables, SVG rendering.
* CI and upstream-watch workflows.
* Initial test suite.
